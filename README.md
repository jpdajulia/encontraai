
# EncontraAí 🔎

Sistema digital de achados e perdidos desenvolvido como projeto acadêmico.

## Objetivo

Facilitar o cadastro, a pesquisa e a localização de objetos perdidos e encontrados, ajudando a devolvê-los aos seus proprietários.

## Funcionalidades

- Cadastro de objetos perdidos e encontrados.
- Pesquisa por nome, descrição e local.
- Filtros por tipo, categoria e status.
- Exibição dos registros em cartões.
- Atualização do status para devolvido.
- Exclusão de registros.
- Armazenamento local dos dados no navegador.
- Interface adaptada para computadores e celulares.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` em um navegador.
4. Para facilitar o desenvolvimento, você pode usar a extensão Live Server do VS Code.

## Armazenamento

Os registros são salvos no navegador utilizado. Nesta versão, os dados não são compartilhados entre diferentes dispositivos.
